GOOD TO KNOW ✦

Questions? Answered.

Does it really turn long videos into short clips? +

Yes. ClipForge uses FFmpeg and audio-based highlight selection to create downloadable clips. This starter version does not claim to match OpusClip's proprietary AI quality.

Can I upload videos from YouTube? +

Public YouTube links work when the optional yt-dlp package is installed. Some links may be restricted. Only import content you own or have permission to use.

Can I add automatic subtitles? +

Yes, with the optional faster-whisper package. Without it, you can still add your own text overlay to any clip in the editor.

Can this become a public SaaS website? +

Yes, with additional development for accounts, secure storage, job queues, AI upgrades, billing and scalable hosting.

Before you get started

Can I use ClipForge for free?

Yes. Run the provided Python and FFmpeg server on your own computer. The self-hosted software has no built-in subscription charge; electricity, hardware, and hosting costs are separate.

Will paying enable AI clipping?

There is no live payment system. Current highlight suggestions use audio analysis, not an OpusClip-equivalent semantic AI model. YouTube imports also depend on provider access and permissions.

How do I enable clipping from my GitHub Pages website?

Deploy the included backend on suitable hosting with persistent storage, authentication, quotas, and monitoring. Then open the studio's Engine settings and enter the secure API URL. The public GitHub Pages site alone cannot run Python.
